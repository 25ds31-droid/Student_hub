Student Hub

One desktop app for the things a student juggles every week: deadlines, exams, study time, notes, money and books. It runs locally in Python and keeps your data on your own computer.

Built with

PythonTkinterSQLitepandasNumPyMatplotlib

Good to know

  • Login and registration, with a separate data folder for each user.
  • Light and dark theme toggle in the top bar.
  • Pages load the first time you open them, so startup stays fast.
  • Only Book Finder needs an internet connection.

Run it on your computer

git clone https://github.com/25ds31-droid/Student_hub.git
cd Student_hub
pip install -r requirements.txt
python main.py
